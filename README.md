## 🔧 Troubleshooting Common Issues

### "jev-bot won't start"

- **Check your antivirus** - Some security software may block new programs. Add jev-bot to your exceptions list.
- **Restart your computer** - A simple reboot often fixes startup issues.
- **Re-download the installer** - The file may have been corrupted during download. Try downloading again.

### "jev-bot can't see my screen"

- **Disable other screen overlay apps** - Programs like screen recorders can interfere.
- **Update your display drivers** - Outdated graphics drivers can cause visibility issues.
- **Check display scaling** - Set your Windows display scaling to 100% for best results.

### "Tasks aren't working correctly"

- **Make sure your screen is unlocked** - jev-bot can't work on a locked screen.
- **Close unnecessary windows** - Too many open windows can confuse the automation.
- **Try simpler tasks first** - Break complex instructions into smaller steps.
